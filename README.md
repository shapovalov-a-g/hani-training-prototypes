# Hani x 4sell training prototypes

Статичные HTML-прототипы системы обучения Hani:

- приложение стажера;
- приложение переобучения;
- админка администратора точки;
- супер-админка сети.

Стартовая страница: `index.html`.

## Просмотр локально

Откройте `index.html` в браузере или запустите любой статичный сервер из корня репозитория.

```bash
python3 -m http.server 8080
```

После публикации GitHub Pages прототипы доступны по публичной ссылке.
